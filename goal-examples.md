# Goal Examples for WealthBoost

WealthBoost can work with many legitimate goals. A goal should describe something the user actually wants to create, change, improve, test, or grow.

## Example goals

- Build a useful mobile app.
- Open a restaurant people return to.
- Bring more clients to an auto repair shop.
- Open a self-service car wash.
- Turn a useful skill into income.
- Grow an online store.
- Turn an idea into a real product.
- Find better freelance clients.
- Improve an existing local business.
- Test whether a new service solves a real problem.

These examples do not limit the app to fixed categories. The most useful profiles explain the actual activity, the intended audience, the current situation, and the desired result.

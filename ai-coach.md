# WealthBoost AI Coach

The WealthBoost AI Coach answers questions using the user's current goal and relevant profile information as context.

Users can ask about a decision, an obstacle, an idea, an offer, a customer or audience, a practical next step, or another subject connected to the goal. Suggested questions can help start a conversation.

Answers use paragraphs, headings, and lists only when those structures improve readability. Useful answers can be saved to Saved Guidance.

AI-generated information can be incomplete or incorrect. Users should verify important information and consult a qualified professional for financial, legal, tax, health, or investment decisions.

What's new in WealthBoost.

The current generation is a complete rebuild centered on one principle: the user's goal should shape the entire experience.

Version 3.0Complete rebuildiPhone and iPad

Version 3.0

WealthBoost 3.0 replaces the previous daily money-plan structure with a simpler goal-guidance model. Users can return whenever they need a perspective, an idea, a next step, or help with a decision.

Goal-focused HomeSee the current goal, a useful perspective, and a practical next move.
Connected AI CoachAsk questions with the current profile already available as context.
Saved GuidanceKeep ideas, next steps, Coach answers, and personal notes.

What changed.

  • A redesigned interface and navigation for iPhone and iPad.
  • New onboarding with one main question per screen.
  • Goal-specific perspectives, plans, ideas, and next steps.
  • An AI Coach connected to the user's current profile.
  • Saved ideas, next steps, Coach answers, and notes.
  • Updated levels, streaks, milestones, widgets, reminders, paywalls, and subscription states.
  • A migration flow for profiles created in earlier versions.

The release remains the source of truth.

The App Store version and release notes determine current availability. Some features described on this site may appear as part of the WealthBoost 3.0 release rollout.
